This binary stores its return addresses and frame pointers in a separate
stack; while we can overwrite those values on the regular stack, it
accomplishes nothing.

<span class="sb" style="box-sizing: border-box; color: #4070a0;">`main()`</span> puts a pointer to <span class="sb" style="box-sizing: border-box; color: #4070a0;">`exit()`</span> in its stack frame, which it jumps to

overflow to instead point to <span class="sb" style="box-sizing: border-box; color: #4070a0;">`jump_to_here()`</span>, which prints the flag.

Conveniently, due to the return-address protection and the fact that
<span class="sb" style="box-sizing: border-box; color: #4070a0;">`start()`</span> doesn't have many meaningful local variables, we don't need
to be careful about the other values we clobber on the stack on the way
to <span class="sb" style="box-sizing: border-box; color: #4070a0;">`main()`</span>'s local function pointer. The correct return addresses are
restored at the end of each function.

Prompts
<span class="k" style="box-sizing: border-box; color: #007020; font-weight: bold;">-</span> Here is the GDB output of registers when the program crashed,

<section id="scoring" style="box-sizing: border-box;">
<h2 style="box-sizing: border-box; font-weight: bold; font-family: 'Roboto Slab', ff-tisa-web-pro, Georgia, Arial, sans-serif; font-size: 24px; margin-bottom: 24px;">Scoring<a class="headerlink" style="box-sizing: border-box; color: #2980b9; cursor: pointer; display: inline-block; font: 14px / 1 FontAwesome; text-rendering: auto; -webkit-font-smoothing: antialiased; opacity: 0; margin-left: 0.5em;" title="Link to this heading" href="https://tc.gts3.org/cs6265/2026-fall/ctf.html#scoring">¶</a></h2>
<p style="box-sizing: border-box; line-height: 24px; margin: 0px 0px 24px;"><em style="box-sizing: border-box;">The details of the scoring may be subject to change!</em>

<p style="box-sizing: border-box; line-height: 24px; margin: 0px 0px 24px;"><span style="box-sizing: border-box; font-weight: bold;">1. CTF scoring</span>

<p style="box-sizing: border-box; line-height: 24px; margin: 0px 0px 24px;">The score in the CTF consists of two parts: attack points and defense points. <em style="box-sizing: border-box;">This is NOT your actual class score – see the next section.</em>

<ul class="simple" style="box-sizing: border-box; margin: 0px 0px 24px; line-height: 24px;">
<li style="box-sizing: border-box; list-style: disc; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">Attack score: up to 500 points for each solved challenge

<ul style="box-sizing: border-box; margin: 0px; line-height: 24px;">
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">Dynamic scoring decreases the points per challenge as more teams solve it

</li>
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">The minimum score for each challenge is 250 (50%)

</li>
</ul>
</li>
<li style="box-sizing: border-box; list-style: disc; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">Defense score:

<ul style="box-sizing: border-box; margin: 0px; line-height: 24px;">
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">0 teams solve your challenge: 0 points

</li>
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">N/2 teams solve your challenge: 2500 points (5 challenges worth)

</li>
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">N teams solve your challenge: 1250 points (2.5 challenges worth)

</li>
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">Otherwise, your score is linearly interpolated within those ranges.

</li>
</ul>
</li>
</ul>
<p style="box-sizing: border-box; line-height: 24px; margin: 0px 0px 24px;"><span style="box-sizing: border-box; font-weight: bold;">2. Translation of CTF score to class score</span>

<p style="box-sizing: border-box; line-height: 24px; margin: 0px 0px 24px;">This only pertains to CS6265 students.

<p style="box-sizing: border-box; line-height: 24px; margin: 0px 0px 24px;">The class score is calculated as the sum of base points and ranking points.

<ul class="simple" style="box-sizing: border-box; margin: 0px 0px 24px; line-height: 24px;">
<li style="box-sizing: border-box; list-style: disc; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">Base points:

<ul style="box-sizing: border-box; margin: 0px; line-height: 24px;">
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">20 points, awarded for solving at least one challenge

</li>
</ul>
</li>
<li style="box-sizing: border-box; list-style: disc; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">Ranking points:

<ul style="box-sizing: border-box; margin: 0px; line-height: 24px;">
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">First-place team, which scored Z CTF points, gets 380 ranking points.

</li>
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">“First-place team” might be either per-section or overall, depending on how many online-section/external teams participate.

</li>
<li style="box-sizing: border-box; list-style: circle; margin-left: 24px;">
<p style="box-sizing: border-box; line-height: 24px; margin: 0px;">Other teams, which scored X CTF points, get 380 * X/Z ranking points.

</li>
</ul>
</li>
</ul>
<p style="box-sizing: border-box; line-height: 24px; margin: 0px 0px 24px;">In other words, the first-place team gets 400 class points, and everyone else’s CTF scores will be scaled accordingly, with a minimum of 20.

<p style="box-sizing: border-box; line-height: 24px; margin: 0px 0px 24px;">Example: Team A scored 1500 points in the CTF, Team B scored 2000 points and wins the competition. Thus, Team B gets 400 class points: 20 base points + 380 ranking points. Team A also gets 20 base points. In addition, they get (1500/2000)*380=300 ranking points (linear scaling). Overall, Team A gets 320 (=20+300) points for the class ranking.

<p style="box-sizing: border-box; line-height: 24px; margin: 0px 0px 24px;">We may increase the base points if the average score is too low. In that case, the maximum possible ranking score decreases by the amount we increase the base points (in other words, the first team will always have 400 points).

</section>
